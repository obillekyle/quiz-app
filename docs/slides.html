QuizApp: a quiz from the module itself, every question with its source

A teacher drops in a module and gets a quiz in about 20 seconds, shares it by link or QR code, sees what the class missed, and prints Set A and Set B with the answer key.

BPC Competitorsokyle.dev

The problem

Quizzes take a teacher's evening, and AI help cannot show its work

Written by hand

Each quiz is typed from the module, then retyped as Set A and Set B, with a key and a table of specifications for the department.

Unchecked AI

Chat tools write questions that sound right. Nothing shows which line of the module a question came from, so every one has to be checked.

Unfair checking

Online forms mark "Ductility" wrong when the key says "ductility", and "five" wrong when it says "5". Essays still need a person.

What it does

From a module to a graded, printed test

Teacher

Drop the module

A PDF or photos of the pages. It is read the moment it is picked.

AI

Draft in about 20 s

Four kinds of question, each quoting its sentence. A chat refines it; a picture per question comes from the module's own figures or Wikimedia Commons.

Teacher

Share

A link and a QR code; a name and a section are enough. Practice checks each answer, Test shows the score at the end, Graded holds it until released.

Respondents

Answer

Feedback after each answer, with the source sentence.

Teacher

See and print

Most missed, what to teach again with the counts, scores as CSV, Set A and B, key, table of specifications.

Grounded by design

Every question cites its sentence, and plain code checks it

CheckNo AI: the quote must appear in the file, word for word after normalizing, or 85% of its words in order.
FlagA quote not in the file is marked, so the teacher checks that question first.
Photos and scansRead once by the AI, word for word, so they can be checked too.

QuizApp4

Honest grading

Exact where it can be, AI where it must, and always labeled

Multiple choiceGraded exactly, in 5 to 11 ms on the server.
True or falseGraded exactly, in English or Filipino (Tama o Mali).
IdentificationCase, spacing and number words ("lima" for 5) first; only a near miss goes to the AI, median 3.1 s.
EssayScored by the AI against the teacher's rubric, 3 to 7.5 s, with a notice that it can be wrong.
The teacher decidesEvery AI verdict is labeled "AI", and any score can be changed. Both AI checks can be turned off: then identification is exact and essays wait for the teacher's score.

QuizApp6

On paper

Set A, Set B, the keys and the table of specifications

  • Laid out as Philippine test papers are: Name and Score, then Test I to IV with directions.
  • Set B moves every question and every option; no multiple-choice letter repeats Set A's at the same number.
  • A table of specifications by topic and level of thinking, weighted by points.
  • Black and white, on short, long or A4 bond.
QuizApp7

How it is built

Vue in front, Node behind, Gemini for the AI

  • Vue 3.5 and Vite on the front.
  • Hono on Node 24, SQLite through bakery-orm; one process serves the API and the pages, behind Apache and Cloudflare at quiz.okyle.dev.
  • Gemini and Gemma models through the Gemini API, a chain per job: a model that refuses rests and the next takes over.

Trust and privacy

Nothing hidden from the teacher, nothing asked of the student

For respondents

A name and no account. Answers never reach the browser before a question is answered. Reports are anonymous.

For teachers

Every AI verdict is labeled and can be changed. Every quote is checked against the file. The AI's note reads counts, not names.
